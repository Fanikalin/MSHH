# VK модуль (MSHH)

Работает через официальный HTTPS API VK (api.vk.com) с **пользовательским
токеном** и longpoll-сервером сообщений.

## Как получить токен

Модулю нужен именно **пользовательский** токен (от имени вашей учётной записи),
как это делают неофициальные клиенты (Kate Mobile, Marusia-обёртки и т.п.):

1. Откройте [vkhost.github.io](https://vkhost.github.io/) (или аналогичный
   генератор токенов на основе «Kate Mobile способа»).
2. Выберите способ **Kate Mobile** → разрешите доступ приложению.
3. Скопируйте полученный токен (длинная строка вида
   `aa1bb2cc...`).
4. Вставьте его в поле «Токен VK» в настройках профиля MSHH.

Права (scope), которые реально нужны: `messages`, `photos`, `docs`, `offline`.

## ⚠️ Предупреждение о рисках

- Пользовательский токен — это **полный доступ к вашему аккаунту**. Не
  публикуйте его нигде.
- Использование неофициальных клиентов формально нарушает правила VK; аккаунт
  **могут ограничить или заблокировать**. Вы делаете это на свой риск.
- Токен может «протухнуть» (смена пароля, выход со всех устройств) — тогда
  получите новый и обновите профиль.
