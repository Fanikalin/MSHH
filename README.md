# MSHH — Мессенджер здорового человека

Универсальный каркас мессенджер-клиента. **Ядро не знает ни одного протокола** —
оно умеет только показывать данные, хранить их и грузить модули. Всё поведение
приносят **модули** — как моды к игре: каждый модуль описывает свой протокол,
правила хранения и отображения. Вы сами решаете, какие мессенджеры использовать:
ядро всегда одно и то же.

Первый рендерер — TUI (ratatui): клавиатурный, панельный, «здоровый».
Рендерер сменяем: модули общаются с ядром декларативными командами (`UiCmd`),
поэтому GUI-движок поверх того же состояния — вопрос нового рендерера, а не
переделки модулей. (Ограничение TUI: картинки/файлы показываются плейсхолдерами.)

Статус: **каркас**. Платформа: Linux (`--list`, `--headless`, TUI).
Дорожная карта: Windows/Android (расширения библиотек уже выбираются по `cfg`),
GUI-рендерер, сетевые примитивы ядра (ABI v2). См. [ARCHITECTURE.md](ARCHITECTURE.md).

## Установка одной командой

```sh
curl -fsSL https://raw.githubusercontent.com/Fanikalin/MSHH/main/install.sh | sh
```

Linux. На Arch ставит нативный `rust` из pacman, на Bazzite и других атомарных
Fedora (Silverblue, Bluefin) — через предустановленный Homebrew, на остальных
дистрибутивах — rustup. Собирает release-бинарник, кладёт `~/.local/bin/mshh` и модуль `echo` в
`~/.local/share/mshh/modules`. Повторный запуск — обновление. Пути можно
переопределить: `MSHH_INSTALL_DIR`, `MSHH_BIN_DIR`, `MSHH_MODULES_DIR`.

## Сборка и запуск

```sh
cargo build                     # ядро + пример-модуль echo
scripts/install-modules.sh      # копирует модули в ~/.local/share/mshh/modules
./target/debug/mshh             # TUI
./target/debug/mshh --list      # какие модули найдены
./target/debug/mshh --headless  # без терминального UI (до Ctrl+C)
```

Модули ищутся в `--modules-dir`, иначе в `~/.local/share/mshh/modules` и `./modules`.

Из коробки работает один модуль — `echo`: локальный чат, сохраняет историю в
SQLite, на каждое отправленное сообщение отвечает «Эхо: …». Это образец SDK:
см. [docs/MODULES.md](docs/MODULES.md) и [modules/echo](modules/echo).

Каталог боевых модулей — отдельный репозиторий
[MSHH-modules](../MSHH-modules): Telegram (grammers), Matrix (matrix-sdk,
E2EE), MAX (Bot API, ограниченный режим), Reticulum (P2P), XMPP, IRC
(TLS-only). Их рейтинги доверия вшиты в ядро — клавиша `m`.

## Управление (TUI)

| Клавиши | Действие |
|---|---|
| ↑/↓, Enter | выбор чата, переход к композеру |
| Tab | переключение чаты ↔ композер |
| Enter (в композере) | отправить |
| PgUp/PgDn, колесо | история |
| m | модули и доверие: рейтинги, бейджи; Enter/клик по ● — факты рейтинга |
| Ctrl+Q | выход |

## Структура

```
crates/mshh-module-api   SDK модуля: C-ABI, модель данных, Session, макрос
crates/mshh-core         ядро: загрузчик .so, SQLite, TUI, runtime
modules/echo             пример-модуль (cdylib)
docs/MODULES.md          как написать свой модуль
ARCHITECTURE.md          устройство ядра, ABI, модели владения
```

## Модель безопасности

Модуль — нативный код с полными правами процесса, как мод игры: ставьте только
чему доверяете. Ядро версионирует ABI (`mshh_abi_version`) и не грузит модули
другой версии; паники модуля перехватываются на границе FFI.
