# MSHH

Мультипротокольный клиент мессенджера: Telegram, WhatsApp, Matrix, XMPP и VK в
одном окне. Основа интерфейса — [Cinny](https://github.com/cinnyapp/cinny):
готовые экраны, компоненты и стиль переиспользуются как есть, протоколы
подключаются модулями, матрикс-чаты открываются в родном чат-вью Cinny.

## Протоколы (входят в поставку)

| Модуль | Вход | Чаты | Медиа | Заметки |
|---|---|---|---|---|
| Telegram | телефон + код (2FA поддерживается) | диалоги, группы, каналы | да | api_id берётся по умолчанию, можно свой |
| WhatsApp | QR-связывание устройства | группы и личные | да | история — из кэша первичной синхронизации (ограничение протокола) |
| Matrix | homeserver + логин/пароль | комнаты в едином списке | — | открываются в родном чат-вью Cinny, шифрование работает там |
| XMPP | JID + пароль | ростер + входящие диалоги | нет | файлы и MAM-история не поддерживаются намеренно |
| VK | пользовательский токен | личные, групповые, сообщества | да | инструкция по токену в `mshh_modules/vk/README.md` |

## Установка

Требования: Linux (проверено на Omarchy/Arch), node ≥ 20, npm.

```bash
git clone https://github.com/Fanikalin/MSHH.git
cd MSHH
./install.sh
mshh
```

`install.sh` собирает интерфейс, кладёт лаунчер `~/.local/bin/mshh`, иконку и
`.desktop`-файл. Перезапуск скрипта обновляет установленную версию.

## Сборка для раздачи (вшить свои api-ключи Telegram)

По умолчанию каждый пользователь Telegram-профиля вводит api_id/api_hash с
my.telegram.org (вшитый публичный fallback ненадёжен — сервер часто его
отклоняет). Чтобы раздать приложение друзьям «только телефон и код»:

```bash
npm run build:share
# или с ключами через env:
MSHH_TELEGRAM_API_ID=123456 MSHH_TELEGRAM_API_HASH=0123... npm run build:share
```

- Ключи записываются в `mshh_modules/telegram/app-defaults.json` — файл
  добавлен в `.gitignore`, в git и в вывод скрипта не попадает (повторный
  запуск перезаписывает).
- У получателей такой сборки форма Telegram предзаполнена с пометкой
  «встроенные ключи — менять не нужно» (можно переопределить своими).
- Готовый артефакт: `dist-share/mshh-share-*.tar.gz` — получатель распаковывает,
  запускает `./install.sh`, затем `mshh`.


## Первый запуск

1. Приложение открывается на экране профилей и чатов.
2. «Добавить профиль» → выберите модуль → заполните форму (генерируется по
   схеме модуля) → подключение.
3. Все чаты всех профилей показываются в едином списке; фильтры — по профилю
   и по модулю.

## Свои модули

Модуль = папка в `mshh_modules/`: `manifest.json` (имя, схема полей, тип
авторизации) + `index.js` (реализация). Форма настройки профиля строится из
схемы автоматически. Полное описание формата и пример —
**[docs/MODULES.md](docs/MODULES.md)**.

## Документация

- `docs/ARCHITECTURE.md` — как устроено приложение (Electron main = ядро и
  модули протоколов, renderer = Cinny + слой MSHH).
- `docs/MODULES.md` — формат модуля для авторов.
- `docs/CINNY_WIRING.md` — полный список точек интеграции с кодом Cinny.
