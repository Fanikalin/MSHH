# Требования к MSHH

Живой файл требований от пользователя. Любой агент: перед началом работы —
прочитать; получив задание от пользователя — дополнить/уточнить здесь и
отметить статус. Выполненное помечать ✅, в работе — 🚧, запланированное — ☐.

## Установка и распространение — ✅

- Установка одной командой на любой Linux: `install.sh` в корне репо.
- Arch — приоритет: нативный `rust` из pacman.
- Bazzite и другие атомарные Fedora (Silverblue, Bluefin): тулчейн на хост не
  ставится (immutable, нет gcc/crt1.o) — сборка в контейнере distrobox
  (ubuntu:24.04), $HOME общий, бинарник появляется на хосте. Без rpm-ostree
  и перезагрузки.
- Остальные дистрибутивы (apt/dnf/zypper/apk): rustup + build-зависимости.
- Повторный запуск = обновление (`git pull --ff-only` + пересборка).
- Защита от `curl | sh` (пересоздание скрипта во temp-файл); канонический
  вызов: `sh -c "$(curl -fsSL …/install.sh)"`.
- Пути: `MSHH_INSTALL_DIR`, `MSHH_BIN_DIR`, `MSHH_MODULES_DIR`,
  `MSHH_BOX`, `MSHH_BOX_IMAGE`.

## TUI — мышь и раскладка — 🚧

- ✅ (было) захват мыши включается; скролл истории, клики по оверлеям
  настроек/менеджера работают.
- ☐ Клик по чату в списке — открыть чат; клик по композеру — фокус;
  клик по строке поиска — фокус поиска.
- ☐ Слева панель как в Telegram: сверху строка поиска (вместо «Аккаунты»),
  кнопка «Настройки», ниже список групп, ниже — чаты.
- ☐ Хот-кеи сохранить (Tab/Enter/Esc/s/m/PgUp/PgDn/Ctrl+Q), но убрать
  строку с их описанием снизу (оставить счётчики профилей/модулей).

## TUI — поиск — 🚧

- ☐ Строка поиска над чатами: ищет по уже существующим чатам (локально) и
  отправляет запрос всем включённым профилям (`__search.query`).
- ☐ Модули отвечают `UiCmd::SearchResults` (ABI v3) — используют свои
  поисковики (как в Telegram). Разрешено менять модули в ../MSHH-modules.
- ☐ Результаты отображаются как обычные чаты; справа в строке — имя модуля
  и кружок доверия к чату (цвет из каталога рейтингов).
- ☐ Выбор результата открывает чат (модуль делает UpsertChat).

## TUI — группы чатов — 🚧

- ☐ Слева перечислены группы; «Все» — без фильтра. Клик по группе — фильтр
  списка чатов (повторный клик — снять).
- ☐ В настройках: раздел «Группы» — список групп, «+ Добавить группу».
- ☐ Мастер: назвать группу → добавлять правила по одному:
  тип чата (бот/канал/группа/люди), модуль, степень доверия,
  отдельный чат. Правило можно удалить (Enter по правилу),
  группу — удалить (с подтверждением).
- ☐ Группы персистентны: `core_groups` / `core_group_rules`.

## TUI — настройки — 🚧

- ☐ Кнопка «Настройки» слева открывает существующее окно настроек (s).
- ☐ Отдельным пунктом настроек — открытие меню модулей и доверия
  (то же, что клавиша `m`).

## TUI — карточка чата и композер — 🚧

- ☐ Справа над чатом — строка профиля собеседника; содержимое определяет
  модуль (`UiCmd::SetChatHeader`; fallback: имя профиля · модуль).
- ☐ Левее поля ввода — кружок аккаунта, от лица которого пишем. Клик —
  выбор конкретного аккаунта модуля этого чата; выбор применяется ко всем
  чатам профиля (`__account.switch`, `AccountView::active`).
- ☐ Аватарки в кружках чатов и аккаунтов: модуль может задать
  (`Avatar::Image{path}` / `Avatar::Initial{text}`); если не задал —
  одноцветный кружок (цвет из имени чата) с первой буквой имени.
- ☐ Модуль может добавить свои кнопки в поле сообщения
  (`UiCmd::SetComposerButtons`: эмодзи, голосовое, кружок, файл и т.д.);
  клик → `__composer.button` с id кнопки.
